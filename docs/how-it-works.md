# 它是怎么做到的

这份文档写给想改代码或者纯粹好奇的人。用户不需要看。

## 1. 占一条边：AppBar

Windows 的 AppBar 就是把屏幕边缘的一条区域"划走"，让其余窗口不再使用它 —— 任务栏就是这么干的。DeadBand 注册 `ABM_NEW` / `ABM_QUERYPOS` / `ABM_SETPOS`，贴 `ABE_BOTTOM`，高度等于预留区。

关键点：**只占边，不占中间**。这也是它能做到"不干扰其它窗口"的原因，也是它天生不支持屏幕中间坏线的原因。

窗口本身是 `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`，不抢焦点、不占 Alt+Tab。

### 全屏的时候怎么办

系统的默认语义是"有全屏应用就让开"（`ABN_FULLSCREENAPP`）。DeadBand 反着来：**绝不让开**，只把自己重新推到顶层栈最上面（`SetWindowPos(HWND_TOPMOST, SWP_NOMOVE|SWP_NOSIZE|SWP_NOACTIVATE)`）。

同时为了不让全屏画面被它压住，程序会主动把全屏窗口**压到区带上沿**：`SetWindowPos` 改对方的矩形，不 hook、不改样式。250ms 一轮复查，最多试 8 次；对方死活不让的话，退化成"覆盖显示"并弹一次提示。

## 2. 坏线：一条数学规则，不是一张图

坏线的模型只有三个参数：

```
每隔 Spacing 行一条，相位 Offset，粗细 Thickness
```

判定就一行取模运算。坐标以**距屏幕底边**为准（0 = 最下面一行），这样坏线的位置是面板的物理属性，区域高度怎么变都不会漂。

渲染分两步：
1. **挖空**：命中的屏幕行清成底色 —— 内容看起来被切开
2. **补竖线**：坏行的竖线要补回来，否则栅格会在这些行断掉

注意这里用的是窗口的**真实位置**（`PointToScreen`）而不是"屏幕底边减去窗口高度"：AppBar 会被系统顶到任务栏上方，两者不总相等。

## 3. 收编：为什么竖线能把横线藏起来

单独看，一条灰线是缺陷。当它旁边每隔同样距离都有一条同色的竖线时，人眼看到的是规则重复的图案 —— 灰线成了格子的一条边。

所以网格的间距要么跟随坏线（正方形栅格），要么和坏线成整数倍关系。`GridFollowLines` 就是这个开关，默认开。

网格色建议直接对着屏幕上的灰线取色（设置 → 外观与其他 → 网格色…，取色器是从屏幕像素上取的）。

## 4. 分层与叠加

四层，从下到上：

```
底色 → 番茄钟水位（仅共存） → 频谱 → 时钟 → 字幕 → 番茄钟控件 → 网格 → 坏线挖空
```

可见性规则（在 `ZoneHost.ComposeLayers` 里）：

- 时钟：开着，且没被"有音频 / 有字幕"的规则藏掉
- 频谱：开着；上面有内容压着时降到用户设定的不透明度
- 字幕：开着且有文本；时钟也显示时宽度收窄、时钟靠右
- 番茄钟独占：上面三层全部不画

**为什么要迟滞**：字幕是一句一句来的，句子之间有半秒空隙。如果按"当前有没有字幕"实时排版，时钟会在中间和靠右之间来回跳。所以音频用 1.5 秒、字幕用 2.5 秒的迟滞窗口 —— 有内容时立刻粘住，没内容时等一会儿再恢复。

## 5. 字幕链路

```
B站 网页播放器
   ↓ Tampermonkey 脚本（读 video.currentTime + 字幕轨 json）
   ↓ http POST 127.0.0.1:41723/feed
DeadBand（FeedServer，裸 TcpListener 手写 HTTP）
   ↓
CaptionFeed → 区带
```

三个细节：

- **不用 HttpListener**：那个要先注册 URL ACL，等于要管理员权限。`TcpListener` 绑 `127.0.0.1` 什么都不用。
- **脚本由程序自己服务**：`/userscript.user.js` 在服务时重写端口号和更新地址，所以用户不需要复制粘贴、程序换端口也不会断。
- **时间轴驱动而不是 DOM 驱动**：脚本按 `video.currentTime` 在字幕 cue 里二分查找当前这句。这样**后台播放、最小化、切标签页**都不会停 —— 只看 DOM 的话，页面一隐藏元素还停在最后一句上。

## 6. 显示器身份

热插拔识别的难点是"换了个接口还算不算同一台屏"。做法是把显示器 ID 归一成**型号段**：

```
MONITOR\HKC2773\{guid}\0001            → HKC2773
\\?\DISPLAY#HKC2773#5&23d…#{guid}      → HKC2773
```

只保留型号段，拔插换口也能认回同一台，配置文件跟着走。

配置文件里还存了 `screendevice`（`\\.\DISPLAY5`），用来在多显示器时精确定位 —— 光靠分辨率会认错，两块同分辨率的屏很常见。

## 7. 为什么到处都是"避让"和"让出"

这个程序的定位是**不干扰**。所以：

- 三层的开关全关时，区带主动放弃顶层窗口（把位置让给用户自己的桌面歌词）
- 有自己人的对话框开着时，不抢顶层（否则设置窗口会被区带盖住按钮）
- 鼠标命中测试只在自己声明的可点区域返回 `HTCLIENT`，其余一律 `HTTRANSPARENT` 穿透到下层窗口

这几条是设计约束，不是补丁。加新功能时别破坏它们。
