# 常见问题

## 区带位置看起来不对 / 和标定时看到的位置差了一截

**九成是任务栏还在屏幕底部。**

DeadBand 用 AppBar 占位，任务栏也在抢同一条边。Windows 会把后来的挤到前一个上方 —— 于是区带浮起来几十像素，和标定预览的位置对不上。

处理：把任务栏挪到顶部、或设成自动隐藏，然后重新进引导（设置 → 外观与其他 → 重新运行首次设置引导）跑一遍预检。

程序检测到这种情况会弹一次气泡提示，并把 `bottomGap` 写进 `%LOCALAPPDATA%\DeadBand\last.txt`。

## 区带完全不见了

按可能性从高到低：

0. **是不是按了隐藏热键**。默认 `Ctrl+Alt+H`，按一下收起、再按一下放回。鼠标停在托盘图标上会提示"区带已隐藏，Ctrl+Alt+H 恢复"。
1. **目标显示器没连上**。外接屏拔掉时程序会自动停用（这是设计），插回来两秒内自动恢复。`last.txt` 里会写「目标显示器未连接，功能已停用」。
2. **三层的开关全关了**，番茄钟也是关。这时候区带只是一块背景板，而且程序会主动让出顶层窗口 —— 因为它不想盖住你自己的桌面歌词。
3. **程序没在跑**。看托盘有没有图标；没有就重新启动。

## 字幕一直是那行示例文字

在设置 → 内容 里把「预览模式」取消勾选。预览模式是调叠加规则用的，开着的时候用示例字幕代替真实内容，关掉设置窗口时也会自动撤销。

## 字幕一句都不来

按顺序查：

1. **播放器里有没有把字幕打开**。DeadBand 只显示播放器已经在显示的那一句；B站 的 AI 字幕/CC 字幕要先在播放器里开。
2. **篡改猴装了没**。字幕靠 Tampermonkey 脚本推送，没装扩展就点脚本，浏览器只会给你看一段代码。
3. **脚本装了没 / 是不是旧版**。设置 → 字幕 → 在浏览器里安装 / 更新脚本。
4. **是不是 B站**。目前只支持 B站 网页播放器，其它站点接不了。
5. **端口冲突**。默认 41723，被占用时会往后找，诊断目录里的 `feed-url.txt` 写着实际端口；脚本由程序自己服务，端口会自动改写，一般不用管。

## 杀软 / SmartScreen 报警

exe 没有代码签名（个人开源项目买不起证书）。第一次运行会被 SmartScreen 拦一次：更多信息 → 仍要运行。

不放心的话自己编译：`build.cmd`，用的是系统自带的 .NET Framework 编译器，产物和自己下载的一模一样。

## 怎么彻底卸载

1. 托盘右键 → 退出
2. 设置 → 外观与其他 → 取消勾选「开机自动启动」（或者任务管理器 → 启动 → 禁用 DeadBand）
3. 删掉程序目录
4. 删掉 `%LOCALAPPDATA%\DeadBand`（配置、日志、浏览器脚本副本都在这里）
5. 浏览器里卸载篡改猴脚本

做完这五步，注册表和磁盘上不会留下任何东西。

## 配置文件在哪 / 能不能直接改

`%LOCALAPPDATA%\DeadBand\`

| 文件 | 内容 |
|---|---|
| `profiles\*.ini` | 每台显示器一份，按型号命名，纯 `key=value` 文本，可以直接编辑 |
| `options.ini` | 应用级选项（是否隐藏播放器自带字幕、是否走过引导） |
| `pomodoro.ini` | 番茄钟状态（重启后能接上） |
| `last.txt` | 最近一次状态和原因，排查全靠它 |
| `feed-log.txt` | 字幕推送的请求日志 |
| `fullscreen.txt` | 全屏避让的每次尝试记录 |

改完 ini 需要重启程序生效；用设置窗口改的话即时生效。

## 换显示器 / 换分辨率要不要重新标定

换**另一台**显示器：程序按型号找配置，没有就当成新设备，进引导给它单独标一份。

同一台显示器换了分辨率（比如从 1080p 换到 1440p）：坏线的物理位置没变，但"距屏幕底边的行数"会变，**要重新标定**。

## 能不能同时服务两块屏

当前版本一次只服务一台。要换：引导第 2 步的显示器下拉里选另一台，它会给那台单独建配置。

## 为什么要有"网格"这一步，不加不行吗

不加也能用，内容照样显示。但坏线会继续在内容上切出几条缝，看起来是"屏幕坏了"。

加上网格之后，竖线与横线同色同距，观众看到的是**一张网**，缝变成了图案。这是这套做法和"贴块黑边盖住"的本质区别 —— 也是它值得存在的理由。
